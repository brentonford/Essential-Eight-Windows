Deploys a WDAC policy implementing ASD Essential Eight application control requirements. On workstations this meets ISM-0843 and ISM-1870 at ML1. On servers this implements ahead of ISM-1490 (ML2 internet-facing servers) and ISM-1656 (ML3 non-internet-facing servers). Uses the AllowAll base template with user-writable path deny rules. Supports Audit and Enforce modes via the WDAC Enforcement Mode parameter.
